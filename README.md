# Claude Skills Sandbox

A private backup of my local Claude Code skills (`~/.claude/skills`), kept as a
sandbox so I can version and track changes to them over time.

## Skills in here

| Skill | What it does |
|-------|--------------|
| build-from-plan | Execute an understood implementation plan with high autonomy |
| commit-pr | Turn finished work into small coherent commits + PR text |
| discovery | Route source-dependent research to the right workflow |
| frontend-design | Frontend design guidance |
| grilling | One-question-at-a-time alignment interviewing for plans |
| humanizer | Rewrite AI-sounding text so it reads naturally |
| poster-design | Help design posters and flyers |
| show-me | Explain the current topic visually with diagrams/sketches |
| slideshow | Slide-by-slide narration for presentations |
| wireshark-analysis | Network packet capture, filtering, and analysis techniques |
| writing-session | Source-grounded PRD / spec / RFC / design-doc work |
